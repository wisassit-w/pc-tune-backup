# 💾 PC Tune Backup & Profile Manager

A specialized **C# (.NET)** desktop application engineered to safely backup, export, and restore customized Windows performance and network optimization profiles.

### Key Features
* 🔄 **Backup & Restore Engine:** One-click export and restoration of Win32 priority separation, mouse/keyboard queue sizes, and registry latency tweaks.
* 🌐 **Network & Hardware Management:** Controls Netsh network stack, LAN adapter driver parameters, MSI Mode settings, and Ultimate Performance power plans.
* 🎮 **FiveM / GTA V Config Sync:** Backs up critical game settings files (`commandline.txt`, `gta5_settings.xml`, `CitizenFX.ini`) with automated System Restore Point creation.
