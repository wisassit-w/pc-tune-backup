โปรแกรมนี้ทำอะไร
------------------------------------------
เก็บค่าที่คุณจูนคอมไว้ (เล่นเกมลื่น เน็ตดี) ลงไฟล์เดียว
พอล้างเครื่องหรือลง Windows ใหม่ ก็เปิดโปรแกรมแล้วกดใส่ค่ากลับได้เลย
ไม่ต้องจ้างร้านจูนใหม่


ใช้ยังไง มีแค่ 3 ขั้น
------------------------------------------

ขั้นที่ 1  เปิดโปรแกรม (ไม่ต้องติดตั้งอะไรเพิ่ม)
  - แตกไฟล์ที่โหลดมา
  - ดับเบิลคลิก PcTuneBackup.exe
  - กด Yes ตอน Windows ถามสิทธิ์ Admin
  - ใช้ได้กับ Windows 10 / 11 ทุกเครื่อง


ขั้นที่ 2  เซฟค่าจูน (ตอนที่คอมลื่นแล้ว)
  - เปิด PcTuneBackup.exe กด Yes ถ้ามีหน้าต่างถาม
  - กดปุ่ม Export (Backup)
  - เลือกที่เก็บไฟล์ แล้วกดบันทึก จะได้ไฟล์ my-tune.exe ไฟล์เดียว
    ที่มีทั้งโปรแกรมและค่าจูนของคุณอยู่ข้างใน (หรือเลือกเป็น .json ก็ได้)
  - เห็นตัวหนังสือสีเขียวว่า Saved แปลว่าเรียบร้อย


ขั้นที่ 3  ใส่ค่ากลับ (หลังลง Windows ใหม่)
  - ลงไดรเวอร์การ์ดจอ และไดรเวอร์เน็ตให้เสร็จก่อน
  - ลง FiveM แล้วเปิดเข้าเกมหนึ่งครั้ง แล้วปิด
  - เปิดไฟล์ my-tune.exe แล้วกดปุ่ม Apply Profile
    (ถ้าเซฟเป็น .json ให้เปิด PcTuneBackup.exe กด Restore แล้วเลือกไฟล์)
  - กด Yes แล้วรอจนเสร็จ
  - รีสตาร์ทเครื่อง 1 ครั้ง


อย่าลืม!
------------------------------------------
ก่อนล้างเครื่อง ให้ก๊อปไฟล์ my-tune.exe (หรือ my-tune.json และ PcTuneBackup.exe)
ไปเก็บไว้นอกไดรฟ์ C (เช่น USB หรือไดรฟ์ E)
ไม่งั้นจะหายไปพร้อมการล้างเครื่อง


ติดปัญหา
------------------------------------------
Q: Windows หรือแอนตี้ไวรัสเตือนตอนเปิดโปรแกรม
A: เป็นเรื่องปกติ เพราะโปรแกรมแก้การตั้งค่าเครื่อง
   กด "More info" แล้วกด "Run anyway"

Q: เห็นบรรทัดสีแดงในช่อง ACTIVITY
A: ค่านั้นใส่ไม่สำเร็จ (เช่น อุปกรณ์ไม่ตรงกับเครื่องเดิม)
   ส่วนอื่นยังใส่ได้ปกติ

Q: ใส่ค่ากลับแล้วเน็ตหรือเกมแปลกๆ
A: เปิด System Restore แล้วย้อนไปที่จุดชื่อ PcTuneBackup
   (โปรแกรมสร้างให้ก่อนใส่ค่ากลับ)


ควรรู้
------------------------------------------
- ใช้ได้ดีที่สุดกับคอมเครื่องเดิมที่เปลี่ยนแค่ Windows
  ถ้าเปลี่ยนเมนบอร์ด บางค่าจะถูกข้าม
- โปรแกรมเก็บเฉพาะการตั้งค่าเครื่องและไฟล์ของคุณเอง
  ไม่ได้แก้ตัวเกม
- ยังไม่ได้ทดสอบกับคอมทุกรุ่น
  เซฟไฟล์ไว้หลายชุดเผื่อไว้จะอุ่นใจกว่า
